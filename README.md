# SICU rotation presentation

A 3D SICU room paired with a locally autosaved presentation worksheet for exactly two rotation records: Patient 1 and Patient 2. The room view presents packet data entered by the student; it does not generate patient physiology or recommend treatment.

Patient 1 starts with the approved adult trauma-abdomen case shape only. Vitals, hospital-day progression, procedures, ventilator settings, and medication details remain blank until verified from rotation records. Patient 2 starts blank.

The worksheet contains the thirteen packet sections and a printable patient presentation. Local drafts autosave in the browser. Private cloud autosave remains owner-only and requires the existing fictional-data confirmation; no local draft is migrated automatically.
